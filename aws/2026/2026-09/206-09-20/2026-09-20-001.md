### Summary of Key Recommendations & Configuration

1. **Recommended Machine Specifications**:
    * **Instance Type**: **`t3.xlarge`** (4 vCPUs, 16 GiB RAM) or **`t3a.xlarge`** (AMD version, ~10% cheaper).
        * *Why*: Compiling C++ / Qt and running Visual Studio 2022 comfortably requires more than 8 GB RAM to avoid
          swapping and sluggish RDP responsiveness.
        * *Budget alternative*: **`t3.large`** (2 vCPUs, 8 GiB RAM) can work for lightweight tasks, though installation
          and builds will be slower.
        * *Avoid Free Tier micro instances (`t2.micro` / `t3.micro`)*: With only 1 GB RAM, the Windows OS and Visual
          Studio installer will crash.
    * **Storage**: **120 GB gp3 SSD** (baseline 3,000 IOPS, 125 MB/s throughput) to accommodate Windows Server (~25 GB),
      Visual Studio 2022 Community with C++ workloads (~35 GB), Qt Creator 20.0.1 + Qt SDK (~25 GB), and temporary build
      caches.

2. **AWS EC2 Setup Workflow**:
    * **AMI**: Select **Microsoft Windows Server 2022 Base** (or **2025 Base**). It provides the complete Windows
      Desktop GUI out-of-the-box and natively runs all standard Windows desktop development applications.
    * **Key Pair**: Generate an RSA `.pem` key pair (`aws-windows-dev-key.pem`) and save it locally; it is required to
      decrypt the initial `Administrator` password.
    * **Security Group**: Open inbound port **TCP 3389 (RDP)** restricted strictly to **`My IP`** (never `0.0.0.0/0`) to
      block internet port-scanning bots.
    * **Auto-assign Public IP**: Ensure this is **Enabled**.

3. **Connecting from your Local PC**:
    * Wait 3–5 minutes after launching for Windows Sysprep setup.
    * In the AWS Console, select your instance, click **Connect > RDP client > Get password**, upload your `.pem` key,
      and decrypt the `Administrator` password.
    * Connect using **Remote Desktop Connection** (`mstsc.exe`) or by downloading the preconfigured `.rdp` file from the
      console.
    * Under `mstsc > Show Options > Local Resources`, enable **Clipboard** and map your **Local Drives** (`C:`) to
      easily drag and transfer project files between your local PC and the VM.

4. **Cost Optimization for Occasional Use**:
    * **Stop the VM when not in use**: You pay compute costs
      (~$0.166/hr) only when running. When **Stopped**, compute drops to **$0.00/hr**, and you only pay pennies per
      day (~$0.32/day) for the EBS storage preserving your installed environment.
    * **Shutting Down**: You can shut down directly from the Windows Start menu or run `Stop-Computer -Force` in
      PowerShell. AWS will detect the shutdown and change the state to `Stopped`.
    * **Dynamic Public IP**: When starting the VM back up, AWS assigns a new public IP; copy it from the console into
      `mstsc`.
    * **Auto-Stop Alarm**: Set a CloudWatch alarm to automatically stop the instance if CPU utilization remains below 5%
      for 60 minutes.

Detailed instructions, PowerShell silent install scripts for Visual Studio 2022 and developer tools, and Qt Creator
