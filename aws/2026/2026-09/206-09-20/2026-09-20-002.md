## Summary

In AWS EC2, **User Data** allows you to provide a bootstrap script that runs automatically when the Windows instance
boots for the first time.

Full instructions and a ready-to-use bootstrap script have been added
to [aws/aws-windows-pc.md (Step 2.8)](file:///C:/usr/src/df/manuals/aws/aws-windows-pc.md#step-28-specify-user-data-optional-bootstrap-automation).

---

### 1. Where to Specify User Data

#### Option A: In the AWS Management Console (During Launch)

1. On the **Launch an instance** page, scroll down to the bottom.
2. Click to expand **Advanced details**.
3. Scroll all the way down to the **User data** field.
4. Select **As text** and paste your script into the box (or click **Browse** to upload a `.ps1` / `.txt` file).

#### Option B: On an Existing Stopped Instance

If you launched the instance without User Data or want to update it:

1. Stop the instance (**Instance state > Stop instance**).
2. Go to **Actions > Instance settings > Edit user data**.
3. Update the script and click **Save**.

#### Option C: Via AWS CLI

```bash
aws ec2 run-instances \
  --image-id ami-0abcdef1234567890 \
  --instance-type t3.xlarge \
  --key-name aws-windows-dev-key \
  --user-data file://bootstrap.ps1
```

### 2. Formatting Rules for Windows Instances

Unlike Linux (which uses `#!/bin/bash`), Windows EC2 launch agents require explicit XML-style tags:

* **PowerShell Script**: Wrap the commands in `<powershell>` and `</powershell>`.
* **Batch / CMD Script**: Wrap the commands in `<script>` and `</script>`.
* **Run-Once vs. Persistent**:
    * By default, User Data executes **only once** on the initial boot.
    * If you want the script to execute on **every reboot**, include the `<persist>true</persist>` tag inside the block.

### 3. Ready-to-Use Bootstrap Script

Paste this directly into the **User data** field in the console. It will automatically disable IE security restrictions,
set the timezone, install Chocolatey, install Git/CMake/Ninja, and silently kick off the Visual Studio 2022 Community
install:

```powershell
<powershell>
# 1. Log all output to inspect progress
Start-Transcript -Path "C:\bootstrap.log" -Append

Write-Output "--- Starting Automated Setup ---"

# 2. Disable IE Enhanced Security Configuration (IE ESC)
Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Active Setup\Installed Components\{A509B1A7-37EF-4b3f-8CFC-4F3A74704073}" -Name "IsInstalled" -Value 0
Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Active Setup\Installed Components\{A509B1A8-37EF-4b3f-8CFC-4F3A74704073}" -Name "IsInstalled" -Value 0
Stop-Process -Name explorer -Force -ErrorAction SilentlyContinue

# 3. Set Timezone (e.g., W. Europe Standard Time)
Set-TimeZone -Id "W. Europe Standard Time"

# 4. Install Chocolatey Package Manager
[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072
Set-ExecutionPolicy Bypass -Scope Process -Force
iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

# 5. Install Git, CMake, Ninja, 7-Zip
choco install -y git cmake ninja 7zip

# 6. Download & Silently Install Visual Studio 2022 Community (C++ Desktop Workload)
$vsUrl = "https://aka.ms/vs/17/release/vs_community.exe"
$vsInstaller = "$env:TEMP\vs_community.exe"
Invoke-WebRequest -Uri $vsUrl -OutFile $vsInstaller

Start-Process -FilePath $vsInstaller -ArgumentList `
    "--add Microsoft.VisualStudio.Workload.NativeDesktop", `
     "--includeRecommended", `
     "--passive", `
     "--norestart" -Wait

Write-Output "--- User Data Finished Successfully ---"
Stop-Transcript
< /powershell>
```

### 4. How to Check User Data Execution & Logs

Once connected via RDP, you can verify execution through the following log files:

* **Custom script log**: `C:\bootstrap.log`
* **EC2Launch v2 system execution log**: `C:\ProgramData\Amazon\EC2Launch\log\agent.log`
